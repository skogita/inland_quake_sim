# inland_quake_sim
Inland earthquake simulator — faults are born and earthquakes repeat in a 2-D crust of particles and bonds, with no fault position given — with a Windows window app (Japanese and English screens) — design docs and code from the book Toward a Million Lines XI / 内陸地震のシミュレータと窓のアプリ（Windows・日英の画面）— 本『LLM で 100 万行のソフトウェア開発 XI』の設計書とコード
